02 Proyectos destacados

Lo que construimos

Cinco entregas que cruzaron varios módulos y terminaron en algo que se puede tocar, probar y mostrar. La primera es la que más lejos llegó.

P.01 ★ Proyecto estrella

SITRAP Sistema Inteligente de Transporte

Aplicación multiplataforma —Android y Windows— para moverse por El Salvador: eliges origen y destino, la app busca las rutas de buses y microbuses y dibuja el recorrido sobre el mapa. Suma un módulo turístico, favoritos, historial y reportes de la comunidad, con base de datos local para funcionar sin internet.

  • Aplicaciones móviles
  • Bases de datos
  • Turismo
  • Mapas

Lo que resuelve

  • Buscador de rutas por origen y destino, cruzando departamentos, municipios y rutas.
  • Mapas interactivos con el trayecto real entre paradas.
  • Catálogo turístico con destinos por departamento.
  • Sesión local con contraseñas encriptadas, favoritos e historial.
  • Reportes de la comunidad para avisar problemas del servicio.

Stack

Flutter · Dart · SQLite · OpenStreetMap · OSRM
VS Code · Android Studio · GitHub · Netlify

03 Acerca

Un repaso para todos

Este portal nació para que ningún compañero se quede atrás: todo el año concentrado en un solo lugar, abierto y sin costo.

«Aprender es poder explicarlo.»

Profesor Javier Arturo García Mineros

Memorias 3DSA reúne los 9 módulos de la especialidad con un lenguaje claro: qué se trabajó, con qué programas, cómo se evaluó y qué recursos sirven para seguir practicando desde casa.

Es un proyecto estático —HTML, CSS y JavaScript puro— pensado para publicarse en GitHub Pages. Cada ficha abre en un modal, incluye un quiz de repaso y enlaza documentación oficial de las herramientas que usamos en clase.
