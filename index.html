Abre el portal con un servidor local

Este proyecto usa módulos de JavaScript, así que necesita servirse por HTTP. En VS Code usa Live Server; también puedes ejecutar python -m http.server en la carpeta del proyecto. En GitHub Pages funcionará sin configuración adicional.

03 Acerca

Un repaso para todos

Este portal nació para que ningún compañero se quede atrás: todo el año concentrado en un solo lugar, abierto y sin costo.

«Aprender es poder explicarlo.»

Profesor Javier Arturo García Mineros

Memoria 3DSA reúne los ocho módulos de la especialidad con un lenguaje claro: qué se trabajó, con qué programas, cómo se evaluó y qué recursos sirven para seguir practicando desde casa.

Es un proyecto estático —HTML, CSS y JavaScript puro— pensado para publicarse en GitHub Pages. Cada ficha abre en un modal, incluye un quiz de repaso y enlaza documentación oficial de las herramientas que usamos en clase.
